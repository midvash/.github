## Lo que construimos

Midvash es un devocional diario con la profundidad del estudio bíblico, en la
web, iOS y Android. Más de 100 traducciones de licencia libre en más de 60
idiomas servidas mediante una API pública gratuita, un lector web cuidado en 9 idiomas
de interfaz con búsqueda de texto completo, estudio asistido por IA, lecturas
diarias, referencias cruzadas, perfiles de personajes bíblicos, comentarios
y un diccionario de teología bíblica. El texto bíblico y el devocional diario son
gratis para todos; la conversación con la IA es parte de Midvash Pro.

## Proyectos open-source

| Repo | Qué |
|------|------|
| **[bible-api](https://github.com/midvash/bible-api)** | API bíblica pública, gratuita y sin clave — versículos, capítulos y versiones en más de 100 traducciones bíblicas de licencia libre, en más de 60 idiomas. Impulsa api.midvash.com. |
| **[bible-mcp](https://github.com/midvash/bible-mcp)** | Servidor MCP gratuito y sin clave para la API bíblica pública — las Escrituras para LLMs desde cualquier cliente MCP. Impulsa mcp.midvash.com. |
| **[bible-data](https://github.com/midvash/bible-data)** | Más de 30 versiones bíblicas de dominio público en más de 20 idiomas, JSON + SQLite, codificadas en OSIS. El conjunto de datos que impulsa nuestro lector. |
| **[bible-data-js](https://github.com/midvash/bible-data-js)** | SDK de TypeScript para el conjunto de datos anterior. `npm install @midvash/bible-data`. |
| **[bible-cross-references](https://github.com/midvash/bible-cross-references)** | 453 referencias cruzadas temáticas curadas, etiquetas multilingües (en, pt, es). |
| **[bible-wordpress-plugin](https://github.com/midvash/bible-wordpress-plugin)** | Plugin de WordPress: detecta automáticamente referencias bíblicas en las entradas y añade enlaces con tooltip al pasar el cursor. |
| **[bible-emdash-plugin](https://github.com/midvash/bible-emdash-plugin)** | Plugin del CMS EmDash: autoenlaza referencias bíblicas con tooltips al pasar el cursor. Impulsado por la API pública de Midvash. |
| **[bible-chrome-extension](https://github.com/midvash/bible-chrome-extension)** | Extensión de Chrome que detecta referencias bíblicas en cualquier página web y las enlaza con un tooltip de vista previa al pasar el cursor. |

Y vendrá más — publicamos las partes de nuestra stack que resultan útiles para otros proyectos (datasets, esquemas, bibliotecas).
